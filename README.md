# Umpire VR — VR野球審判トレーニング

大学の実験の授業で共同制作した、野球の一塁判定を体験するVRアプリです。走者とボールの到着を観察して判定し、正誤とリプレイで振り返ることを目指しました。

**このリポジトリは第三者アセットを除いたソース公開版です。** 授業で作成したC#コード、シーン設定、Unityの設定・依存パッケージ一覧を掲載しています。モデル、テクスチャ、モーション、フォント、SDK本体、サンプルは同梱していません。クローンしただけで授業時と同じVR体験が動く状態ではなく、不足する素材・参照の復元が必要です。

## 実装した内容

| 内容 | 主なソース |
| --- | --- |
| 投球・打球・一塁への送球 | `Assets/Script/Program/BallController.cs` |
| 打撃・走塁・スライディング | `Assets/Script/Program/Bater_script.cs` |
| ボールと走者の到着順の比較 | `Assets/Script/Program/GameManager.cs` |
| 判定入力、正誤表示、やり直し | `Assets/Script/GameController.cs` |
| 記録フレームの取得とリプレイ | `Assets/BBB_8752tris/Script/` |
| Meta Questコントローラー入力 | `Assets/controllersetting.cs`、`Assets/Scenes/MetaQuestButtonHandler.cs` |
| タイトル・ルール・ゲーム画面 | `Assets/Scenes/Title.unity`、`Rule.unity`、`BaseBall.unity` |

## 開発環境

- Unity 6000.0.25f1
- C#、Universal Render Pipeline
- Meta XR SDK 71.0.0
- XR Interaction Toolkit 3.0.7 / Input System 1.11.2

依存関係は `Packages/manifest.json` と `Packages/packages-lock.json` に記録しています。パッケージ本体は各配布元から取得してください。

## ソースを確認・復元するには

1. Unity HubからUnity 6000.0.25f1でこのフォルダを開きます。
2. Package Managerの依存関係を解決します。
3. [アセット確認記録](docs/ASSET_AUDIT.md)を参照し、使用権を持つ素材を元の配布元から自分で用意するか、自作素材に置き換えます。
4. シーン内の欠落するモデル、フォント、マテリアル、アニメーション、XRリグ等の参照を設定し直します。
5. タイトル・ルール・野球シーンの遷移、判定UI、リプレイ用カメラを接続して確認します。

シーンには素材へのGUID参照が残っています。素材を再配布するためのリポジトリではなく、ゲームロジックと制作構成を紹介するための公開です。XR/Meta関連の元のシーン内設定にも別途復元が必要なものがあります。
